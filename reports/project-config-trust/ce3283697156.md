## The delta

- **`TestLoadUpstreamCAsEscapes` (`driver/upstreamca_test.go:509-525`).** The
  expected message is now built from `filepath.Abs("/no")` and
  `filepath.Separator`, and on Windows the invalid byte is expected as U+FFFD.
  The Windows conversion (`syscall.FullPath` to UTF-16 replaces 0xff with
  U+FFFD; `GetFullPathName` gives `C:\no\such...`) yields exactly that string,
  and it matches the "got" line of the native log
  (`branch-3733c4b-go-test.log`, line 15). The product is unchanged. On Linux
  and darwin the expectation is the same string as before, so the test still
  fails on an unescaped newline, ESC or invalid byte. The design's line that a
  path is printed absolute and escaped, including a byte that is not valid
  UTF-8 (design 1003-1005), stays true: on Windows the byte is already a valid,
  printable character before anything escapes it. GLOBAL-07 and TEST-01: the
  fix makes the test portable rather than skipping it.
- **Guide (`first-build.md:40-46`, `configuration.md:92-97`).** The text
  agrees with the code and the design: `errNotRegular` ("not a regular file",
  `cmd/warden/config.go:274`) after a stat that follows links, `errTooLarge`
  ("larger than 1 MiB", `config.go:233`), and named files read with neither
  limit (Decision 14, Defaults and overrides). The anchor
  `#building-a-repository-you-do-not-control` exists
  (`configuration.md:64`). UX-01 holds.

## Findings

### F2: GLOBAL-06, MUST-review: `driver/session.go:275` (carried forward)

This change crosses the security boundaries:

- Trust roots sent across the host-relay boundary are re-encoded valid PEM only.
- The user-level config file is removed.
- `ModuleRoot` searches from the executable only.
- The default config file is read only if it is a regular file, and only up to 1 MiB.

The design's Security note covers all of this (**What remains**, 10). The
delta adds nothing to the boundary.

**Fix:** no code change. The human acknowledges this at merge, with the
Security note in the PR body. TEST-08's adversarial arm runs before the release
that carries the change.
