## Findings

### F1: FLOW-06, MUST (also GLOBAL-09, SHOULD): `cmd/warden/config.go:171`

`readConfigFile` refuses a `./warden.toml` that is not a regular file once
links are followed, such as a link to `/dev/zero`, a terminal or a FIFO. A file
named by `--config` or `WARDEN_CONFIG` is read whatever kind of file it is.
The fix pass added this in `d153126`. The reference documents it
(`configuration.md:28`, `overview.md:35`) and a test covers it
(`configfile_test.go:257`).

The approved design does not decide this:

- Its lookup is "`./warden.toml` exists -> it".
- The only errors for that file are a `stat` failure other than "does not exist" and a file that cannot be read.
- Its row for the default file in **Defaults and overrides** has no such condition.
- Security note item 10 weighs the same hazard for CA paths that a repository's `warden.toml` names, and leaves it as `main` has it. It does not discuss the config file itself.

On `main`, such a file is read, and the read hangs or exhausts memory. The
behavior is conservative and sound. But it is a design decision made in code,
and code alone does not name a change to a default.

**Fix:** back-to-design (FLOW-06), recommended. Design names the condition and the
asymmetry in the default's row, in **How the config file is found** and in
Security note item 10. A delta review approves it, and the code stays as it is.
The other fix is to remove the `errNotRegular` case with its reference text and
its test.

### F2: GLOBAL-06, MUST-review: `driver/session.go:275`

This change crosses the security boundaries:

- Trust-root handling across the host-relay boundary changes. Only valid PEM certificates, re-encoded, are sent. They are read once, before anything is created, and the claim opens no file.

- `ModuleRoot` no longer takes the working directory's `go.mod` as warden's source tree. That was a way for a repository to run code on the host.

The design carries the Security note this rule requires, accepted at r1, and
says TEST-08 runs.

**Fix:** no code change. The human acknowledges this at merge, with the Security
note in the PR body. TEST-08's adversarial arm runs before the release that
carries the change.
