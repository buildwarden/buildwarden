1. **FLOW-17** (GLOBAL-07, UX-04), `Makefile:68`.
   - **What's wrong:** the `tier1` target builds the tool with the caller's `GOOS`/`GOARCH`, which breaks `GOOS=<os> make lint`.
     - FLOW-17 and `CONTRIBUTING.md:74` both ask for that per-platform lint.
     - The command produces a binary for the target OS, which line 69 cannot run. Verified on linux with `GOOS=darwin`: `Syntax error: "(" unexpected`.
     - `EXE` also follows the host's `$(OS)`, not the build target.
     - After merge, no agent can lint another platform's build-tagged files.
   - **Suggested fix:** build for the host and run with the inherited `GOOS`, so the analyzers and golangci still load the target: `GOOS=$$(go env GOHOSTOS) GOARCH=$$(go env GOHOSTARCH) go build ...`, with `EXE` from `GOHOSTOS`. Add `GOOS=windows make lint` and `GOOS=darwin make lint` on linux to acceptance.

     - The repository has no `no-design` label yet, although `CONTRIBUTING.md:76` tells contributors to use it.
   - **Suggested fix:**
     - On push, pass `-no-design`: the PR run already enforced FLOW-01. Alternatively, look up the merged PR's labels through the REST API.
     - Add `types: [opened, synchronize, reopened, labeled, unlabeled]`.
     - Put a note in the PR body for Jeff to create the label.
