# `redacted` metadata schema, v1

| | |
|---|---|
| `$id` | `https://github.com/buildwarden/buildwarden/schemas/v1/redacted.json` |
| Machine schema | [`metadata-redacted/v1.schema.json`](https://github.com/buildwarden/buildwarden/blob/main/specs/metadata-redacted/v1.schema.json) |
| Applies to | Any record whose original metadata has been stripped or was never recorded |
| Default header index | 4 (see the ledger spec's [Default Schemas](../build-ledger/v1.md#default-schemas)) |

## Purpose

Attribution for removed metadata. Because metadata is outside every signature,
a holder may replace a record's metadata with this schema (changing the schema
index byte and the CBOR content) without invalidating the ledger; see
[Redactability](../build-ledger/v1.md#redactability). The owner tells a
downstream consumer whom to ask for the full metadata.

## Fields

```cbor
{
  "owner": "build.example.com"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `owner` | text | yes | Identifier of the party responsible for or owning the redacted information |

No other fields are allowed.
