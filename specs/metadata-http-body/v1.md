# `http-body` metadata schema, v1

| | |
|---|---|
| `$id` | `https://github.com/buildwarden/buildwarden/schemas/v1/http-body.json` |
| Machine schema | [`metadata-http-body/v1.schema.json`](https://github.com/buildwarden/buildwarden/blob/main/specs/metadata-http-body/v1.schema.json) |
| Applies to | `checkpoint` or `close` records whose payload is an HTTP request or response body |
| Default header index | 2 (see the ledger spec's [Default Schemas](../build-ledger/v1.md#default-schemas)) |

## Purpose

Carries the response status alongside a body, so a reader can tell a
successful download from an error page without the response headers.

## Fields

```cbor
{
  "status": 200
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `status` | unsigned int, 100–599 | no | HTTP response status code. Present only for response bodies; a request body's metadata is an empty map. |

No other fields are allowed.
