# `http-open` metadata schema, v1

| | |
|---|---|
| `$id` | `https://github.com/buildwarden/buildwarden/schemas/v1/http-open.json` |
| Machine schema | [`metadata-http-open/v1.schema.json`](https://github.com/buildwarden/buildwarden/blob/main/specs/metadata-http-open/v1.schema.json) |
| Applies to | `open` records of HTTP/HTTPS channels |
| Default header index | 0 (see the ledger spec's [Default Schemas](../build-ledger/v1.md#default-schemas)) |

## Purpose

Names the request a channel carries: what was asked for, from where, and over
which protocol version. It is the metadata most often stripped by
[redaction](../build-ledger/v1.md#redactability), because the URL reveals
hosts and paths.

## Fields

```cbor
{
  "method": "GET",
  "url": "https://example.com/path",
  "protocol": "HTTP/1.1"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `method` | text | yes | HTTP method (`GET`, `POST`, `PUT`, `DELETE`, `HEAD`, ...) |
| `url` | text (URI) | yes | Full request URL, including scheme, host and path |
| `protocol` | text | yes | Protocol version (`HTTP/1.1`, `HTTP/2`, ...) |

No other fields are allowed.
