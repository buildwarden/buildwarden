# `environment-container` metadata schema, v1 (legacy)

| | |
|---|---|
| `$id` | `https://github.com/buildwarden/buildwarden/schemas/v1/environment-container.json` |
| Machine schema | [`metadata-environment-container/v1.schema.json`](https://github.com/buildwarden/buildwarden/blob/main/specs/metadata-environment-container/v1.schema.json) |
| Applies to | The environment record in ledgers written before typed environments |
| Status | **Legacy.** The relay no longer writes it. It is kept so those ledgers resolve. |

## Purpose

Before environment types were specified, the environment record's metadata
schema was `environment-container.json` and the only environment was a
container image. New ledgers reference
[`environment`](../metadata-environment/v1.md) instead.

## Compatibility

A ledger that uses this schema has the header label
`"environment": {"type": "container"}`. Readers treat that label as
[`oci-image/v1`](../environment-oci-image/v1.md). The signed payload is the raw
OCI manifest bytes with no `type` member, which is exactly an `oci-image/v1`
payload, so the reader takes the same type from the payload itself.

## Fields

```cbor
{
  "reference": "docker.io/library/python:3.12-slim",
  "digest": "sha256:<64 hex>",
  "mediaType": "application/vnd.oci.image.manifest.v1+json"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `reference` | text | yes | Image reference as specified by the user |
| `digest` | text, `sha256:<64 lowercase hex>` | yes | OCI manifest digest |
| `mediaType` | text | no | Manifest media type |

No other fields are allowed. All of them are informational and unsigned.
