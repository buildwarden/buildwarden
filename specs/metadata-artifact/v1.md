# `artifact` metadata schema, v1

| | |
|---|---|
| `$id` | `https://github.com/buildwarden/buildwarden/schemas/v1/artifact.json` |
| Machine schema | [`metadata-artifact/v1.schema.json`](https://github.com/buildwarden/buildwarden/blob/main/specs/metadata-artifact/v1.schema.json) |
| Applies to | `artifact` records |
| Default header index | 3 (see the ledger spec's [Default Schemas](../build-ledger/v1.md#default-schemas)) |

## Purpose

Names a build output. The record type already marks the payload as an
artifact; this metadata says where to find it in the output directory.

## Fields

```cbor
{
  "name": "my-binary",
  "context": {
    "content_type": "application/octet-stream"
  }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | text | yes | Filename as stored in the ledger's `artifacts/` directory |
| `context` | map | yes | Freeform key-value map for additional artifact metadata; may be empty |

No other fields are allowed.
